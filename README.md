# NASA-FireWatch

Satellite-based wildfire monitoring and analysis using NASA FIRMS data.

## Data

The original FIRMS download archives for this project are in [`data/raw/`](data/raw/). See [`data/raw/README.md`](data/raw/README.md) for archive contents, download request IDs, attribution, and the NASA disclaimer.

## Attribution

We acknowledge the use of data and/or imagery from NASA's Fire Information for Resource Management System (FIRMS), part of NASA's Land, Atmosphere Near real-time Capability for Earth observations (LANCE) and NASA's Earth Science Data and Information System (ESDIS).

## Disclaimer

NASA FIRMS data are provided “as is.” Users are responsible for their use. FIRMS cautions that the spatial resolution and other characteristics make the data unsuitable for tactical decision-making or informing about conditions at a local scale. See the [NASA FIRMS data citation and disclaimer guidance](https://www.earthdata.nasa.gov/earth-observation-data/near-real-time/citation#ed-firms-citation).

This project is independent and is not affiliated with or endorsed by NASA.
